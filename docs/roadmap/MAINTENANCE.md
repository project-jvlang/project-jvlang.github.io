# ロードマップドキュメント管理

このディレクトリには、jv言語の開発ロードマップドキュメントが含まれています。

## ディレクトリ構造

```
docs/roadmap/
├── README.md          # このファイル
├── index.md           # ロードマップ概要ページ
├── phase1.md          # Phase 1: コア言語基盤
├── phase2.md          # Phase 2: 型システム
├── phase3.md          # Phase 3: 数学型システム + 初期配布
├── phase4.md          # Phase 4: 標準ライブラリ拡充
├── phase5.md          # Phase 5: 開発ツールチェーン
├── phase6.md          # Phase 6: エコシステム拡張
├── phase7.md          # Phase 7: 高度な最適化
└── _template.md       # 新規フェーズページ用テンプレート
```

## ドキュメント更新方法

### 手動更新

1. 対応する `phaseX.md` ファイルを編集
2. チェックボックスのステータスを更新:
   - `✅` : 完了
   - `🔄` : 進行中
   - `⬜` : 未着手
3. 概要セクションのステータスバッジを更新
4. ビルドして確認: `mkdocs build`

### 自動同期（今後実装予定）

現在、以下の自動化オプションを検討中です：

#### オプション1: GitHub Issues連携
- `../project-jv/.project-todolist/phase*.md` の内容をGitHub Issueに同期
- GitHub Actions で Issue → Docs 変換
- 完全自動化が可能

#### オプション2: ローカル同期スクリプト
- Pythonスクリプトで phase checklist を読み取り
- ロードマップドキュメントを自動生成
- ファイル監視で自動更新

## ステータスの意味

### フェーズステータス
- 🟢 **完了**: 実装完了、テスト済み
- 🟡 **進行中**: 現在実装中
- ⚪ **未着手**: 今後実装予定

### タスクステータス
- ✅ 完了したタスク
- 🔄 進行中のタスク
- ⬜ 未着手のタスク

## 新規フェーズの追加

新しいフェーズを追加する場合：

1. `_template.md` をコピーして `phaseX.md` を作成
2. プレースホルダーを実際の内容に置換
3. `mkdocs.yml` の `nav` セクションに追加
4. `index.md` にフェーズ情報を追加

## 注意事項

- **自動生成警告**: 各ページには自動生成ドキュメントである旨の注意書きがあります
- **同期頻度**: 現時点では手動更新ですが、将来的に自動化予定
- **テンプレートファイル**: `_template.md` は nav から除外されています（ビルドには含まれません）
